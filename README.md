## GitHub Pages 發布方式

1. 登入 GitHub，建立新的 Repository，例如 `ai-hr-portfolio`
2. 將本資料夾內所有檔案上傳到 Repository 根目錄
3. 進入 Repository 的 `Settings`
4. 點選 `Pages`
5. 在 `Build and deployment` 中選擇：
   - Source：Deploy from a branch
   - Branch：main
   - Folder：/(root)
6. 儲存後，GitHub 會產生網址：
   `https://你的帳號.github.io/ai-hr-portfolio/`
